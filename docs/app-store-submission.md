## 2. 앱 정보 문안

### 프로모션 텍스트

대한민국 곳곳의 여행지를 발견하고, 나만의 방문 기록과 컬렉션을 만들어 보세요.

### 설명

Handdam은 대한민국의 여행지를 발견하고 직접 방문한 장소를 나만의 도감으로 기록하는 여행 앱입니다.

주요 기능:

- 지도에서 지역별 여행지와 장소 정보 탐색
- 현재 위치를 활용한 여행지 방문 인증
- 사진으로 남기는 나만의 방문 기록
- 관심 장소 즐겨찾기
- 지역별 컬렉션과 방문 진행도 확인
- 카카오 또는 Google 계정으로 간편한 로그인

여행을 계획할 때는 새로운 장소를 발견하고, 여행을 다녀온 뒤에는 나만의 기록을 차곡차곡 모아 보세요.

### 키워드

여행,국내여행,여행기록,여행지도,여행지추천,대한민국,방문인증,여행컬렉션

### 심사 메모

앱은 여행지 탐색과 방문 인증을 제공하는 서비스입니다.

1. 앱을 실행합니다.
2. 로그인 화면에서 제공된 심사용 계정으로 로그인합니다. 로그인 없이도 일부 지도 탐색 기능을 사용할 수 있습니다.
3. 지도 또는 목록에서 장소를 선택합니다.
4. 방문 인증을 선택하면 위치 권한과 카메라 권한이 요청됩니다.
5. 위치 권한은 선택한 여행지 주변 여부를 확인하는 데 사용합니다.
6. 카메라는 방문 인증 사진 촬영에 사용합니다.
7. 인증 후 컬렉션과 마이페이지에서 기록을 확인할 수 있습니다.

위치와 카메라 권한은 방문 인증 기능을 사용할 때만 필요합니다. 광고 추적을 위해 IDFA를 사용하지 않습니다.

## 4. App Privacy 설문 초안

최종 선택은 실제 백엔드 DB와 SDK의 데이터 처리 방식에 맞춰야 합니다.

| 데이터 유형 | 수집 여부 초안 | 사용 목적 | 사용자와 연결 | 추적 목적 |
|---|---:|---|---:|---:|
| 이름/닉네임 | 예 | 앱 기능, 계정 관리 | 예 | 아니오 |
| 이메일 주소 | Google 로그인에서 제공되는 경우 예 | 계정 관리 | 예 | 아니오 |
| 사용자 ID | 예 | 앱 기능, 계정 관리 | 예 | 아니오 |
| 위치 정보(정확한 위치) | 방문 인증 시 예 | 앱 기능 | 예 | 아니오 |
| 사진/동영상 | 방문 인증 사진 저장 시 예 | 앱 기능 | 예 | 아니오 |
| 사용자 생성 콘텐츠 | 방문 기록·컬렉션 데이터 저장 시 예 | 앱 기능 | 예 | 아니오 |
| 진단 데이터 | 분석/오류 SDK를 실제 사용하면 예 | 앱 기능, 분석 | 연결 여부 확인 | 아니오 |
| 광고 데이터/식별자 | 현재 사용 안 함 | 해당 없음 | 해당 없음 | 아니오 |

위치와 사진이 기기에만 일시적으로 사용되고 서버에 저장되지 않는다면 해당 데이터의 “수집” 답변은 달라질 수 있습니다. 또한 Sentry, Firebase Analytics, Expo 서비스 등 별도 SDK를 사용하는 경우 진단·사용 데이터 항목을 추가 확인해야 합니다.
